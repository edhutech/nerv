# Code of Conduct

Be respectful, constructive, and inclusive in Issues, Discussions, pull requests, and other project spaces. Harassment, personal attacks, discrimination, and disruptive behavior are not acceptable.

If you experience or observe unacceptable behavior, report it privately to `[private contact removed]`. Reports will be handled respectfully and as confidentially as practical.

Project maintainers may remove content or participation that violates this code.
