# Start a Task

Use this when one approved Agentic Task is ready for implementation.

## Your task

Prepare to implement the selected Task directly from the Task file.

Do not create a manual Run file.

## Read first

- The selected Task file from `agent-workspace/tasks/`
- The parent Build file from `agent-workspace/builds/`
- Relevant product docs from `agent-workspace/product/`
- `agent-workspace/method/commit-system.md`

## Inspect the repo

Inspect only files relevant to the selected Task.

## Output

Return a short implementation plan with:

- Task ID and title
- Parent Build
- Files to inspect first
- Expected implementation steps
- Validation plan
- Do not do list
- Commit checklist reminder

## Approval rule

After showing the implementation plan, stop and wait for approval before implementing unless the user explicitly asks you to proceed.
