# User Context

## Primary user

Developers who work with coding agents inside software repositories.

They may use Codex, Claude Code, OpenCode, Cursor or similar coding agents.

## MVP focus

The MVP focuses on developers working individually.

Do not write the product as if the MVP is for teams or companies. Future commercial layers can exist later.

## User situation

The user already has or is building a software project.

They use coding agents to move faster, but they often face these problems:

- The agent does not understand the product.
- The agent forgets previous decisions.
- The agent works with incomplete context.
- The agent expands scope without permission.
- The developer repeats the same explanations.
- The developer spends time correcting avoidable mistakes.
- The developer loses continuity between sessions.

## User desired outcome

The user wants to:

- Start work faster.
- Give agents clearer context.
- Reduce repeated explanations.
- Keep work scoped.
- Save decisions and progress.
- Continue work across sessions.
- Improve quality of agent outputs.
- Spend fewer tokens on context reconstruction.

## Product principle for this user

Nerv should feel like a developer tool, not a documentation chore.

The developer should feel that Nerv helps them get better agent output with less manual explanation.
