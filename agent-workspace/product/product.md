# Nerv Product

## What is Nerv?

Nerv is an Agent Work Harness local-first for developers who work with coding agents.

Nerv does not replace coding agents.

It works with agents such as Codex, Claude Code, OpenCode, Cursor or similar tools by preparing the right context, scope, decisions and execution path for each unit of work.

## Core idea

Less context, better chosen.

Nerv should not overload the agent with long documents. It should give the minimum useful context needed to execute a specific task well.

## Product promise

Help your agents build better software with real context.

## Product position

Nerv is not another coding agent.

Nerv is the layer around coding agents that turns vague developer intent into scoped, contextual and verifiable agentic work.

## Category

Agent Work Harness.

This name is preferred because Nerv is not only about context. It supports the work lifecycle around agents:

- Product context
- Repo context
- Decisions
- Agentic Builds
- Agentic Tasks
- Runs
- Checkpoints
- Reviews
- Close
- Product evolution

## Target user

Developers who work with coding agents inside software repositories.

The MVP focuses on developers using Nerv individually in their own repos.

Team, Startup and Enterprise layers can exist later, but they are not part of the MVP.

## Core problem

Coding agents often work with incomplete, scattered or outdated context.

Developers repeatedly explain:

- Product goals
- Repo structure
- Previous decisions
- Current task scope
- Acceptance criteria
- Validation commands
- What changed in previous sessions

This creates rework, wasted tokens and lower quality outputs.

## Nerv solution

Nerv creates a local-first workflow that connects product context, repo context, decisions, tasks, builds, runs, checkpoints, review and close.

It gives coding agents a focused entrypoint for each run, instead of asking them to guess context from the whole repo.

## Product principle

Nerv should reduce friction, not add process.

Every command, file and prompt should help the developer or the agent work better.
