# Nerv Vision

## Long-term vision

Nerv should become the best local-first work harness for developers who build software with coding agents.

It should help developers keep continuity and quality across the full cycle of agent-assisted development:

1. Before talking to the agent
2. During agent work
3. After the agent finishes
4. Between sessions

## Ideal state

In the ideal state, Nerv understands the repo and the product well enough to help developers:

- Create scoped Agentic Tasks from vague intent.
- Detect when intent is too large and should become an Agentic Build.
- Generate focused context for the agent.
- Track runs, checkpoints, reviews and closes.
- Preserve decisions and product evolution.
- Continue work across sessions without repeating everything.
- Work with any agent or coding tool.
- Use the least amount of context needed for the best result.

## What Nerv is not

Nerv is not:

- A coding agent
- A replacement for Codex, Claude Code, OpenCode or Cursor
- A project management app
- A documentation platform
- A cloud-first team platform in the MVP
- A system that dumps all context into prompts

## Future layers

After the developer-first core is loved and polished, Nerv can grow into:

- Team
- Startup
- Enterprise

These layers may need sync, permissions, auditability, governance, collaboration and integrations.

They should not distract from the MVP.
