# Local Clean-Context Fixture

`scripts/smoke-cli.mjs` creates a temporary Git repository that contains:

- `AGENTS.md`
- Access to the canonical skill at `.agents/skills/nerv-development/SKILL.md`
- Product Context generated by `nerv product`
- Repo Context generated by `nerv repo`
- An active Run with generated `run.md`, `task.md`, and checkpoint

The fixture then launches `scripts/fresh-local-evaluator.mjs` as a separate Node process. It reads only persisted authority and Run artifacts and invokes `node dist/index.js current` and `node dist/index.js status` to reconstruct the active Run. The smoke assertion verifies the evaluator result and that the canonical skill's documented `node dist/index.js status` invocation was exercised.

This is a repository-local precondition test for the clean-session procedure in `SKILL.md`. It does not claim that a specific agent host discovered the skill automatically, that a new host session was opened, or that a model followed the procedure. Those claims require host-specific execution evidence.
